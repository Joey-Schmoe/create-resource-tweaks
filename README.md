# Create: Resource Tweaks
Adds various recipes intended to make some basic non-renewable resources, well, renewable.

## Resources

  * Cobbled Deepslate
  * Dripstone
  * Copper
  * Scorchia
    * *Note: Scorchia is already renewable, but requires dyeing Scoria manually or with Create: Dragons Plus. This mod adds a seperate process recipe, and leaves the original in place*
  * Zinc


## Recipes

### Compacting
  * Cobblestone (x4) > Cobbled Deepslate

### Spouting (Lava)
  * Scoria > Scorchia

### Spouting (Water)
  * Limestone > Dripstone

### Crushing
   * Dripstone > Copper Nuggets  **(Overrides original crushing recipe, but not the milling recipe)**
