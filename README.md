# Create: Resource Tweaks

Adds various recipes intended to make some basic non-renewable resources, well, renewable.

## Resources

  * Cobbled Deepslate
  * Calcite
  * Dripstone
  * Copper
  * Scorchia
    * *Note: Scorchia is already renewable, but requires dyeing Scoria manually or with Create: Dragons Plus. This mod adds a seperate, "vanilla" Create process recipe*
  * Zinc

## Recipes

### Compacting

  * Cobbled Deepslate: Cobblestone (x4)
  * Calcite: Cobblestone + Quartz + Lava (100mb)

### Crushing

  **These are Crushing Wheel exclusive - they don't add Milling recipes**

   * Copper Nuggets: Crushing Dripstone Block  (Adds a Crushing recipe, leaving the default Clay Ball milling recipe)
   * Zinc Nuggets: Crushing Scorchia

### Spouting

  * Scorchia: Scoria + Lava (100mb)
  * Dripstone Block: Limestone + Water (250mb)
