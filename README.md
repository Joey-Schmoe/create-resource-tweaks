# Create: Resource Tweaks

Adds various recipes intended to make some basic non-renewable resources, well, renewable.

## Recipes

### Compacting

  * Cobblestone (x4) => Cobbled Deepslate
  * Cobblestone + Quartz + Lava (100mb) => Calcite

### Crushing

  **These are Crushing Wheel exclusive - they don't add Milling recipes**

   * Dripstone Block => Copper Nuggets (12% chance, 2 Nuggets)
     * Adds only a Crushing recipe, leaving the default Clay Ball milling recipe
   * Scorchia => Zinc Nuggets (12% chance, 3 Nuggets)

### Filling (Spout)

  * Scoria + Lava (100mb) => Scorchia
  * Limestone + Water (250mb) => Dripstone Block
