# Create: Resource Tweaks
Adds various recipes intended to make some basic non-renewable resources, well, renewable.

## Resources

  * Cobbled Deepslate
  * Dripstone
  * Copper
  * Scorchia
  * Zinc


## Recipes

### Blasting
  * Scoria > Blasting > Scorchia

### Spouting (Water)
  * Limestone > Dripstone

### Crushing
   * Dripstone > Copper Nuggets  **(Overrides original crushing recipe, but not the milling recipe)**
