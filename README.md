# Create: Resource Tweaks

Adds various recipes intended to make some basic non-renewable resources, well, renewable.

## Tuff Creation

Tuff can be created by Heated Compacting Cobbled Deepslate, Potion of Infestation, and one pre-metal product from each chain - Gravel, Dripstone Block, Scorchia, and Red Sand - producing 5 Tuff per run. Crushing Tuff (the unchanged base Create recipe) gives a 10% chance of each of the four nuggets per Tuff. This results in a consistent increase in nuggets generated per-input, and acts a capstone to combine all four product chains.

### Tuff vs. Processing Directly

Figures are expected averages, per input item or per run.

| Metal | Input | Direct process | Direct yield | Via Tuff (per run) | Tuff vs. direct |
|---|---|---|---|---|---|
| Iron | Gravel | Washing | 0.12 nuggets (12% x 1) | 0.50 nuggets | 4.2x |
| Copper | Dripstone Block | Crushing | 0.24 nuggets (12% x 2) | 0.50 nuggets | 2.1x |
| Zinc | Scorchia | Crushing | 0.36 nuggets (12% x 3) | 0.50 nuggets | 1.4x |
| Gold | Red Sand | Washing | 0.36 nuggets (12% x 3) | 0.50 nuggets | 1.4x |
| **Total** | One of each | | **1.08 nuggets** | **2.00 nuggets** | **1.85x** |

## Recipes

### Compacting

  * Cobblestone (x4) => Cobbled Deepslate
  * Cobblestone + Quartz + Lava (100mb) => Calcite
  * Cobbled Deepslate + Gravel + Dripstone Block + Scorchia + Red Sand + Potion of Infestation (50mb) = Tuff (x5)

### Crushing

  **These are Crushing Wheel exclusive - they don't add Milling recipes**

   * Dripstone Block => Copper Nuggets (12% chance, 2 Nuggets)
     * Adds only a Crushing recipe, leaving the default Clay Ball milling recipe
   * Scorchia => Zinc Nuggets (12% chance, 3 Nuggets)

### Filling (Spout)

  * Scoria + Lava (100mb) => Scorchia
  * Limestone + Water (250mb) => Dripstone Block
